Configuration, une seule fois

Les coches sont enregistrées dans une base de données gratuite Firebase que vous créez. Comptez cinq minutes.

  1. Allez sur console.firebase.google.com, connectez-vous avec un compte Google et créez un projet (vous pouvez désactiver Google Analytics).
  2. Dans le menu Build, ouvrez Realtime Database, cliquez sur Créer une base de données, choisissez un emplacement en Europe, puis le mode verrouillé.
  3. Ouvrez l’onglet Règles, remplacez tout le contenu par le texte ci-dessous, puis cliquez sur Publier.
  1. Dans l’onglet Données, copiez l’adresse qui commence par https:// et se termine par firebasedatabase.app, puis collez-la ici.
